# GeoTerminal 2.2

**Нативная интерактивная лаборатория геометрии для Windows.** GeoTerminal объединяет параметрические 2D/3D-модели, геометрические построения, сечения плоскостями, векторные измерения и интерактивную лабораторию единичной окружности в компактном настольном приложении на C++20, wxWidgets 3.2 и OpenGL.

> **Языки документации:** [Русский](README.ru.md) · [English](README.md)

## Возможности

- **15 параметрических моделей:** равнобедренный и прямоугольный треугольники, квадрат, прямоугольник, окружность, правильный многоугольник, куб, параллелепипед, тетраэдр, октаэдр, цилиндр, конус, призма, пирамида и сфера.
- **Параметры и измерения в реальном времени:** количество вершин, рёбер и граней, а также определённые моделью длины, площади, периметры, диагонали и объёмы.
- **Интерактивная 3D-сцена:** вращение, панорамирование, масштабирование, изометрический вид, виды сверху/спереди/справа, перспективная и ортографическая проекции.
- **Три режима отображения:** затенённые поверхности, каркас со скрытыми рёбрами и совмещённый режим поверхностей с рёбрами.
- **Выбор объектов:** просмотр вершин, рёбер и граней; координаты точки и длина выбранного ребра.
- **Построения:** пользовательские точки, отрезки, прямые и лучи. Точки можно размещать на XY или задавать явными координатами XYZ.
- **Сечения плоскостями:** координатные или произвольные плоскости, многоугольник пересечения, подсвеченный контур сечения, число вершин, площадь и периметр.
- **Векторный анализ:** вектор `AB`, его длина, середина отрезка и углы с координатными осями.
- **Тригонометрия:** интерактивная единичная окружность, отрицательные углы и несколько оборотов, значения синуса/косинуса/тангенса и точная запись распространённых углов через π.
- **Переносимая сборка Windows:** каталог `portable/` содержит исполняемый файл и необходимые runtime DLL.

## Быстрый запуск

1. Открой каталог [`portable/`](portable/).
2. Запусти `GeoTerminal.exe`.

Переносимая сборка не требует установленного Python, MSYS2 или отдельной установки wxWidgets. DLL должны оставаться рядом с EXE.

Также можно запустить `./run.ps1` из PowerShell. Если переносимый EXE отсутствует, скрипт вызовет сборку.

## Сборка из исходников

Скрипт сборки рассчитан на Windows 10/11 и среду **MSYS2 UCRT64**. Требуются CMake 3.24+, GCC и MinGW Make в `C:\msys64\ucrt64`, wxWidgets 3.2 (компоненты `core`, `base`, `gl`) и библиотеки разработки OpenGL.

Запусти из корня репозитория:

```powershell
./build.ps1
```

Скрипт конфигурирует CMake, собирает приложение и тесты геометрического ядра, запускает CTest, затем пересоздаёт `portable/` и копирует необходимые runtime DLL рядом с исполняемым файлом.

Для ручной сборки и запуска тестов после конфигурации:

```powershell
cmake --build build-native --parallel 6
ctest --test-dir build-native --output-on-failure
```

Подробности: [Сборка и разработка](docs/BUILDING.ru.md).

## Основное управление

| Действие | Управление |
|---|---|
| Вращение камеры | СКМ + движение, в любом инструменте |
| Панорамирование | ПКМ + движение |
| Масштабирование | Колесо мыши |
| Вращение в режиме навигации | ЛКМ + движение |
| Действие активного инструмента | ЛКМ |
| Стандартные виды | `0` изометрия, `1` сверху XY, `2` спереди XZ, `3` справа YZ |
| Сетка / оси / подписи | `G` / `A` / `L` |
| Навигация / выбор / точка | `O` / `S` / `P` |
| Отрезок / прямая / луч | `T` / `N` / `Y` |
| Сброс камеры | `R` |
| Удалить выбранную пользовательскую точку | `Delete` |
| Вернуться к навигации | `Esc` |

Горячие клавиши не перехватывают ввод, пока фокус находится в текстовом или числовом поле. Сценарии работы с инструментами описаны в [руководстве пользователя](docs/USER_GUIDE.ru.md).

## Структура проекта

```text
src/       Геометрическое ядро, OpenGL viewport, тригонометрия и wxWidgets UI
tests/     Тесты геометрии и пересечения плоскостей
tools/     Скрипт сбора runtime DLL
portable/  Готовый EXE для Windows и runtime DLL
docs/      Руководства на русском и английском
```

Геометрические вычисления отделены от GUI. Отрисовка использует `wxGLCanvas` и OpenGL; браузерный движок и тяжёлый 3D-движок не встраиваются.

## Текущие ограничения

- В текущем интерфейсе нет сохранения и загрузки файлов проектов. Геометрия создаётся интерактивно и не сохраняется как документ.
- Инструменты отрезка, прямой и луча задают точки на рабочей плоскости XY. Для точек в других местах 3D-пространства используй поля XYZ.
- Сечение вычисляется по рёбрам сетки и отображается как подсвеченный многоугольник поверх модели. Настоящее булево разрезание, удаляющее одну часть тела, пока не выполняется.
- Криволинейные объекты представлены полигональными сетками, поэтому их сечения являются приближениями на основе сетки.
- Предоставленные скрипты сборки и упаковки ориентированы на Windows и MSYS2 UCRT64.
